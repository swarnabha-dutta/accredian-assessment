# 📦 Installation & Setup

Clone the repository

```bash
git clone <repository-url>
```

Move into the project

```bash
cd accredian-enterprise
```

Install dependencies

```bash
npm install
```

Run development server

```bash
npm run dev
```

Open

```
http://localhost:3000
```
